E-commerce Delivery & Refund Analytics
Project Overview
This project analyzes 100,000 delivery records from major Indian quick-commerce platforms (Blinkit, Swiggy Instamart, and JioMart) to identify factors affecting customer satisfaction and refund rates.

Key Insights
High-Risk Categories: Perishables like Fruits & Vegetables and Grocery have the highest refund rates (~46.7%), suggesting a need for better quality checks.

Delivery Performance: While all platforms average a ~3.2 rating, JioMart slightly leads in service rating despite the competitive landscape.

Customer Behavior: Delivery delays show a minimal impact on ratings in this dataset, indicating that product quality might be the primary driver of satisfaction.

Tech Stack
Language: Python

Libraries: Pandas (Data Cleaning), Matplotlib/Seaborn (Visualization)

Environment: Google Colab / VS Code
